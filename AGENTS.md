# Odradek Studio publishing source

This is the curated publishing repository. Development history, research notes,
hardware records, personal presets and drafts belong in private odradek-lab.
Never merge or push Lab history into this repository. Bring reviewed app changes
as explicit source exports, with public content and installer contents checked.

- Reuse the existing Bot Crossing Engine, CameraRig and Blockbench asset rig.
- Preview arrows, learning, ghost arms and imported sessions never authorize or
  execute physical movement. Keep existing Controller checks intact.
- Keep camera images in memory. Never commit recordings, personal photos,
  credentials, machine configuration or runtime/commissioning data.
- Verify the curated component inventory, public footprint, relevant tests,
  viewer build and a fresh-data packaged backend before a release.
- Preserve third-party notices and licenses. Do not grant a new license for
  original code without the owner's explicit choice.
- Use a new version for changed release bytes. Never replace a verified binary.
